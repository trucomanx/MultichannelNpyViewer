# multichannel-npy-viewer

Multichannel NPY Viewer


## Install from PYPI

The homepage in pipy is https://pypi.org/project/multichannel_npy_viewer/

```bash
pip install --upgrade multichannel_npy_viewer
```

Using:

```bash
multichannel-npy-viewer
```

## Install from source
Installing `multichannel-npy-viewer` program

```bash
git clone https://github.com/trucomanx/MultichannelNpyViewer.git
cd MultichannelNpyViewer
pip install -r requirements.txt
cd src
python -m build
pip install dist/multichannel_npy_viewer-*.tar.gz
```
Using:

```bash
multichannel-npy-viewer
```

## Uninstall

```bash
pip uninstall multichannel_npy_viewer
```
